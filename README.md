# 经营类授信调查报告 AI 初审 Skill

用于辅助审核私营小微企业主经营类授信贷前调查报告。Skill不依赖固定模板，而是理解客户经理实际填写的内容，完成事实归一化、适用规则选择、确定性复算、公开信息辅助判断、客户业务初审和报告质量评价。

> 本项目用于贷前调查报告辅助初审，不替代审批官、征信核验、押品审查、法律审查或最终授信决策。

## 当前版本

- Skill：`1.0.0`
- 规则库：`1.0.0`
- 业务本体：`1.0.0`
- 审核规则：34条
- 输出语言：简体中文

这是GitHub正式维护的初始基线。后续版本从`1.0.0`开始按语义化版本规则迭代。

## 核心能力

- 适应不同调查报告模板和客户经理写法；
- 检查申请方案、经营情况、资产负债、关联企业和还款来源是否实质完整；
- 根据抵押、保证等担保方式启用相应条件规则；
- 重新测算流动资金需求、主营同比、净资产和抵押率；
- 检查报告内金额、收入等数字是否前后一致；
- 评价客户经理综合分析是否有事实依据；
- 形成AI对客户及本次授信业务的独立初审判断；
- 在主体可靠匹配时使用公开工商、司法、监管和行业信息辅助判断；
- 保留证据、规则状态和版本信息，支持审计与复现。

## 分析链路

```text
读取报告
  → 建立证据台账
  → 语义归一化
  → 判断产品和担保条件
  → 选择34条适用规则
  → 确定性复算与交叉核验
  → 公开工商与行业辅助判断
  → AI独立客户业务初审
  → 报告质量与客户经理分析评价
  → 业务初审结果 / 后台审计记录
```

## 使用方式

在WorkBuddy或兼容平台安装Release中的ZIP后，可直接引用：

```text
/operating-loan-report-review 审核附件中的经营类授信调查报告。
```

需要完整追溯记录时：

```text
/operating-loan-report-review 审核附件，并附后台审计追溯记录。
```

## 输出原则

默认先回答“客户及本次业务怎么样”，再回答“调查报告写得怎么样”。

业务阅读结果默认隐藏规则编号、证据编号、全部通过项、不适用项，以及因未提供报告外材料而没有运行的规则。

公开信息部分只展示能够形成的有效业务判断。无法可靠匹配、无法判断、查询日期、来源链接、行业参考资料和检索过程仅保留在后台审计记录中。

## 数据与安全边界

- 不要向仓库提交真实客户报告、流水、税务、征信、权证或评估材料；
- 未取得的报告外材料不能假装已经核验；
- 报告缺项只降低相关判断置信度，不能自动认定为客户负面风险；
- 公开信息只有在主体可靠匹配后才能归入客户名下；
- AI初审意见不是最终审批结论。

详细设计见[运行逻辑与文件说明](docs/运行逻辑与文件说明.md)。
