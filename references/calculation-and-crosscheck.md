# 计算与交叉核验

## 计算原则

显示公式、输入值、单位、期间、结果和容差。输入缺失时不得反推或编造；写 `NOT_RUN_MISSING_INPUT`。

## 流动资金需求

服务类常用口径：

`资金需求 = 应收账款 + 预付账款 + 其他应收款 - 应付账款 - 预收账款`

生产/贸易类常用口径：

`资金需求 = 应收账款 + 预付账款 + 存货 - 应付账款 - 预收账款`

若报告或银行制度明确采用其他公式，优先按报告公式复算，并同时说明与常用口径差异。不得仅凭企业名称推定类型。

## 常用复算

- 同比增长率：`(本期 - 上期) / 上期`；上期为零时不可计算。
- 净资产：`资产合计 - 负债合计`。
- 押品净值：按报告明确的扣除项计算，不自行添加扣除。
- 抵押率：`本次以该押品担保的授信金额 / 认可押品价值`。先确认分子是否包含存量授信、分母是评估值还是认定值。
- 申请金额与资金需求：申请金额原则上不应无解释地高于测算需求；超出时标记 WARN 并要求说明。

默认金额等式容差为 0.01 万元，比例容差为 0.1 个百分点；若报告四舍五入精度更低，应披露实际采用容差。

## 冲突处理

冲突并非自动认定造假。先排除不同主体、期间、含税口径、合并/单体、累计/单月和四舍五入。仍无法解释时标记 `WARN` 或 `MANUAL_REVIEW`，列出证据双方并提出核对项。
